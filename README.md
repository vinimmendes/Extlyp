# Cyber Extraction

Jogo de extracao multiplayer (co-op contra jogadores + mundo hostil) para Android, em Unity 6, 2D top-down.
Inspiracao: Darkwood (visao limitada, escuridao, atmosfera pos-apocaliptica).

- Design: `GDD.md`
- Como montar o projeto: `SETUP_PASSO2.md`
- Bots jogadores (Facil, Medio, Dificil): `BOTS_SETUP.md`
- Servidor dedicado no PC, ate 3 salas de 5 e bots apos 30 segundos: `SERVER_SETUP.md`
- Acampamento pessoal, madeira, pregos e bandagens: `CAMP_ITEMS.md`

## Roteiro
1. Um jogador, sem rede (feito)
2. Dois jogadores em rede
3. Cone de visao e mira
4. Vida e tiro (servidor)
5. Monstro com IA simples
6. Extracao e fim de partida

Regra: so avancar quando o passo anterior funcionar em dois aparelhos.
