# Espreitador encapuzado — estudo visual

Variante solicitada em 2026-10-12. Parte do Espreitador rastejante anterior e acrescenta capuz com abertura, rosto oculto, manto de tecido gasto e mãos voltadas para a frente.

- `espreitador-encapuzado.blend`: modelo editável, pose estática, esqueleto preservado.
- `pose-topo.png`: render da perspectiva de jogo.
- `pose-perspectiva.png`: render para inspecionar o volume.
- `build_hooded.py`: criação reproduzível da variante no Blender 4.5.

Este é um estudo para avaliação visual. Não substitui o personagem atual no jogo e não contém novas animações. O modelo anterior em `../StalkerCrawler` foi preservado. O manto ainda precisa receber deformação antes de animar esta variante.
