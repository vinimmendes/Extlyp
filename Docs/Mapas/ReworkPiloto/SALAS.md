23/10/2026. **Somente R17 recebeu o novo conjunto.** O usuário autorizou a expansão e reforçou a ordem ideia → conceito. Estas fichas são a base histórica; o desenvolvimento atual das 24 cenas está em [Ideias das salas](../ReworkCompleto/IDEIAS_DAS_SALAS.md). Identidade dos oito setores, nomes e layout preservados.
